Technical implementation and limitations

The public example is generated from a small fictional fixture, with four supplier offers, two products and four quantity scenarios. Its standalone HTML uses tested Python outputs; the separate, private eight-page Power BI report has been saved and refreshed in Desktop. This web page is not an embedded Power BI report or a live pricing service.

In the sample, landed cost includes merchandise, shipping and applicable order charges. Sales margin uses revenue excluding VAT. One-supplier mixed-product baskets are implemented in the downloadable engine, but this on-screen table compares independent single-product orders.
